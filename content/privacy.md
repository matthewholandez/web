## What this site collects

This site does not ask you to create an account, fill out forms, or submit personal information. If you email me, I’ll have whatever you include in that message.

## Analytics

This site uses [Vercel Web Analytics](https://vercel.com/docs/analytics) to understand basic traffic — for example, which pages are viewed and roughly how often. Vercel’s Web Analytics is designed to be privacy-friendly: it does not use cookies for analytics, and it does not collect or store personal identifiers such as your name, email address, or full IP address for this purpose.

## Cookies and local storage

This site does not set analytics cookies. Your browser may still keep normal technical data needed to load pages (for example, cached files).

## Third parties

The site is hosted on [Vercel](https://vercel.com). Requests to the site go through Vercel’s infrastructure, which may process standard request data (such as IP address, user agent, and timestamps) as part of hosting and security. Analytics data is processed by Vercel as described in their documentation and privacy policy.

## How data is used

Analytics data is used only to understand how the site is used and to improve it. It is not sold, and it is not used for advertising.

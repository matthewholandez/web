# mholandez.com

Personal site for Matthew Holandez — Next.js 16 (App Router), plain CSS, MDX.

```bash
pnpm install
pnpm dev      # http://localhost:3000
pnpm build
pnpm lint
```

| Route | Source |
| --- | --- |
| `/` | `content/about.md` |
| `/now` | `content/now/*.md` |
| `/projects` | `app/projects-data.ts` |
| `/time` | `app/time/` countdown |

Design system: `DESIGN.md`.
